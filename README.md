# RI Student Environment

## Project Information

**Project:** RI Student Environment  
**Student:** Leanetsi Mpongwana  
**Module:** Web Development Project  
**Project Phase:** Part 1 — Building the Foundation: Project Initiation and Planning  
**Year:** 2026

---

## 1. Project Overview

RI Student Environment is a proposed student-focused website designed
to provide a central digital environment where students can discover
programmes, events, student leadership information, community
activities and opportunities for participation.

The website aims to improve access to student-related information
while providing a structured environment for student engagement and
community interaction.

---

## 2. Project Objectives

The main objectives of the project are to:

- Provide students with a central source of information.
- Improve access to student programmes and opportunities.
- Provide information about upcoming student events.
- Present information about student leadership and the SRC.
- Encourage communication and community participation.
- Provide a clear and accessible website structure.
- Create a foundation for future interactive functionality.

---

## 3. Target Users

The primary users of the website are:

- Students
- Student representatives
- Student community groups
- Prospective participants in student programmes

---

## 4. Website Pages

The planned website contains the following pages:

1. Home
2. About
3. Programs
4. Events
5. SRC
6. Community
7. Our Impact
8. Join Us
9. Login
10. Contact

---

## 5. Main Features

The Part 1 website foundation will include:

- Site-wide navigation
- Structured HTML pages
- Student programme information
- Event information
- SRC information
- Community information
- Organisation information
- Impact information
- Registration interface
- Login interface
- Contact information
- Semantic HTML5 structure

Interactive functionality will be developed during later project phases
where required.

---

## 6. Technology

The project will use:

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub

Part 1 focuses primarily on the HTML foundation and project
documentation.

CSS and responsive design will be developed during Part 2.

JavaScript, enhanced form functionality, SEO and deployment will be
developed during Part 3.
